# FeedLink AI — Backend

Backend services for FeedLink AI, an AI-powered food redistribution platform.

## Frontend
https://github.com/Hamza0053/feedlinkFrontend

## Live Application
https://feedlink-vert.vercel.app/

## Tech Stack

- Node.js
- Express
- TypeScript
- PostgreSQL
- Neon
- Google Gemini
- JWT
- bcrypt

## Main Services

- Authentication
- Donation Management
- AI Food Analysis
- Smart NGO Matching
- Notifications
- Impact Statistics
- Role-Based Authorization

## AI

Google Gemini is used for:
- Food urgency analysis
- Shelf-life estimation
- Food safety recommendations
- Recommended actions
- Explainable NGO matching

## Database

PostgreSQL hosted on Neon.

## Running Locally

npm install

npm run dev
